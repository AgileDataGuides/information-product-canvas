# PPTX Export -- PowerPoint Generation for Information Products

**Date:** 2026-03-31

## What's New

- **Client-side PPTX generation using PptxGenJS** -- PowerPoint files are generated entirely in the browser using PptxGenJS, requiring no server-side processing. Users can export their IPC models to .pptx with a single click.

- **Layout matches the Agile Data Guides Google Slides IPC template** -- The generated slides faithfully reproduce the official Agile Data Guides IPC template layout, ensuring consistency with the established methodology.

- **Green header bar with key fields** -- Each Information Product slide features a green header bar displaying the IP Name, Product Owner, and T-Shirt Size fields, matching the standard IPC template.

- **Canvas grid with bordered cells** -- The IPC grid layout is rendered with bordered cells for Personas, Business Questions, Core Business Events, Feature Stories, and Will/Won't columns, preserving the visual structure of the canvas.

- **Vision section with green pill badges** -- The Vision statement is broken into FOR, WHO, THE, THAT, and UNLIKE components, each displayed as a green pill badge for clear visual separation.

- **CC BY-SA 4.0 footer with Agile Data Guides branding** -- Each slide includes a footer with Creative Commons Attribution-ShareAlike 4.0 licensing and Agile Data Guides branding.

- **Title slide with model overview** -- The first slide displays the model name, description, and total Information Product count, providing context for the deck.

- **One slide per Information Product** -- Each Information Product in the model gets its own dedicated slide with the full canvas layout.

- **Available in both SA toolbar and CP sub-header** -- The PPTX export button appears in the standalone app toolbar and in the Context Plane sub-header, accessible from either mode.
