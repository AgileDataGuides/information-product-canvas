# Vision, Delivery Types, Data Sync, and Outcomes Now Support Multiple Items

**1 April 2026**

AgileDataGuides today released an update to the Information Product Canvas that allows Vision, Delivery Types, Data Sync, and Outcomes sections to hold multiple items instead of a single value.

## The Problem

Real Information Products rarely have a single delivery type or a single vision statement. A product might be delivered as both an interactive dashboard and a data extract. Its vision might span multiple statements covering who the product is for, what problem it solves, and how it differs from the current approach. The original canvas limited these sections to a single text value, forcing teams to cram multiple ideas into one field or lose important detail.

## The Solution

Four canvas sections have been upgraded from single-value text fields to multi-item lists:

| Section | Before | After |
|---------|--------|-------|
| **Vision** | One text field | Multiple vision statements |
| **Delivery Types** | One text field | Multiple delivery types |
| **Data Sync** | One text field | Multiple sync approaches |
| **Outcomes/Actions** | One field on a business question | Multiple outcome items on the canvas |

Each item in these sections can now be added, edited, reordered, and deleted independently — the same as personas, business questions, and other multi-item sections.

## How It Works

Click the **+** button in any of these sections to add a new item. Double-click to edit. Existing canvases are automatically upgraded — the app detects old single-value format and converts it to the new multi-item format on load, with no manual migration required.

## Key Benefits

- **Capture the full picture** — no more squeezing multiple ideas into one field
- **Backwards compatible** — old canvas files load and upgrade automatically
- **Consistent experience** — all sections now work the same way
- **Better exports** — each item appears as its own entry in JSON and PowerPoint exports

Multi-item support is available now in the latest release.
