# Information Product Canvas Gets a Redesigned Toolbar

**30 March 2026**

AgileDataGuides today released a redesigned toolbar for the Information Product Canvas, making it faster and easier to manage multiple canvases.

## The Problem

As teams created more canvases, switching between them and managing exports became cumbersome. The original toolbar was functional but did not scale well for users working with many Information Products.

## The Solution

The new toolbar provides a streamlined workflow for canvas management:

- **Model switcher** — a dropdown showing the current canvas name, with one-click switching between all saved canvases
- **New Canvas** — an inline toggle that expands to a text input with Create and Cancel buttons, so users never leave the page
- **Save indicator** — a Save/Saved button that reflects whether there are unsaved changes
- **Export and Import** — dedicated buttons for JSON export, JSON import, and PowerPoint export

The import function auto-detects file format, accepting both native canvas JSON and graph format files without any manual configuration.

## Key Benefits

- **Faster switching** — jump between canvases in one click
- **Clear save state** — always know whether your changes are saved
- **Inline canvas creation** — create a new canvas without navigating away
- **Consistent design** — follows the AgileDataGuides design system for a familiar experience across all pattern template apps

The redesigned toolbar is available now in the latest release.
