# Contributing

Thanks for your interest in contributing to the Information Product Canvas!

## Getting Started

1. Fork the repository
2. Clone your fork
3. Run `./start-IPC.sh` to install dependencies and start the dev server
4. Make your changes
5. Submit a pull request

## Development

The app is built with SvelteKit 5 + Svelte 5 runes, Tailwind CSS 4, and TypeScript.

```bash
cd app
pnpm install
pnpm dev --port 5115
```

## What to Contribute

- Bug fixes
- Accessibility improvements
- New export formats
- Documentation improvements
- Translation / i18n

## Code Style

- TypeScript with strict mode
- Svelte 5 runes (`$state`, `$derived`, `$effect`)
- Tailwind CSS for styling
- No unnecessary abstractions — keep it simple
